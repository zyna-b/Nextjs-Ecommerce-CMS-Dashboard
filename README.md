## 🚀 **Quick Start Guide**

### 📋 **Prerequisites Checklist**
Before starting, ensure you have:

- ✅ **Node.js** 18.0 or higher ([Download](https://nodejs.org/))
- ✅ **npm** or **yarn** package manager
- ✅ **PostgreSQL** database ([Setup Guide](https://www.postgresql.org/download/))
- ✅ **Cloudinary** account ([Sign up](https://cloudinary.com/users/register_free))
- ✅ **Clerk** account ([Sign up](https://clerk.com/))
- ✅ **Git** for version control

### ⚡ **One-Click Setup** (Recommended)

Deploy to Vercel with one click and set up environment variables:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fzyna-b%2FNextjs-Ecommerce-CMS-Dashboard&env=DATABASE_URL,NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY,CLERK_SECRET_KEY,NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME,FRONTEND_STORE_URL&envDescription=Required%20environment%20variables&envLink=https%3A%2F%2Fgithub.com%2Fzyna-b%2FNextjs-Ecommerce-CMS-Dashboard%23environment-variables)

### 🔧 **Manual Installation**

### Installation

**Step 1: Clone & Navigate**
```bash
# Clone the repository
git clone https://github.com/zyna-b/nextjs-ecommerce-cms-dashboard.git

# Navigate to project directory
cd nextjs-ecommerce-cms-dashboard
```

**Step 2: Install Dependencies**
```bash
# Using npm (recommended)
npm install

# Or using yarn
yarn install

# Or using pnpm (fastest)
pnpm install
```

**Step 3: Environment Configuration**
```bash
# Copy environment template
cp .env.example .env.local

# Edit the .env.local file with your credentials
nano .env.local  # or use your preferred editor
```

**Step 4: Configure Environment Variables**

Create a `.env.local` file with the following variables:

```env
# Database Configuration
DATABASE_URL="postgresql://username:password@localhost:5432/ecommerce_cms_db?schema=public"

# Clerk Authentication (Required)
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY="pk_test_your_key_here"
CLERK_SECRET_KEY="sk_test_your_secret_here"
NEXT_PUBLIC_CLERK_SIGN_IN_URL="/sign-in"
NEXT_PUBLIC_CLERK_SIGN_UP_URL="/sign-up"

# Cloudinary (Required for image uploads)
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME="your_cloud_name"
CLOUDINARY_API_KEY="your_api_key"
CLOUDINARY_API_SECRET="your_api_secret"

# Frontend Store URL (Optional - for multi-store setup)
FRONTEND_STORE_URL="http://localhost:3001"

# Stripe (Optional - for payment processing)
STRIPE_API_KEY="sk_test_your_stripe_key"
STRIPE_WEBHOOK_SECRET="whsec_your_webhook_secret"
```

**Step 5: Database Setup**
```bash
# Generate Prisma client
npx prisma generate

# Push database schema (for development)
npx prisma db push

# Optional: Seed database with sample data
npx prisma db seed
```

**Step 6: Launch Development Server**
```bash
# Start development server with Turbopack (faster)
npm run dev

# Or start with standard Next.js
npm run dev

# Server will be available at http://localhost:3000
```

### 🎉 **Success!**
Your e-commerce CMS dashboard should now be running at `http://localhost:3000`

**Default Admin Access:**
- Navigate to `/sign-up` to create your admin account
- The first registered user automatically gets admin privileges

## ❓ **Frequently Asked Questions (FAQ)**

<details>
<summary><strong>🚀 Getting Started Questions</strong></summary>

**Q: Can I use this for a production e-commerce site?**  
A: Absolutely! This CMS is production-ready with enterprise-level security, performance optimizations, and scalable architecture.

**Q: Do I need coding experience to use this?**  
A: Basic setup requires minimal coding. However, customizations will benefit from React/Next.js knowledge.

**Q: What's the difference between this and Shopify/WooCommerce?**  
A: This is a fully customizable, self-hosted solution with no transaction fees, complete code ownership, and unlimited customization possibilities.

**Q: Can I use this for multiple stores?**  
A: Yes! Multi-store functionality is built-in, allowing you to manage multiple brands from one dashboard.

</details>

<details>
<summary><strong>🛠️ Technical Questions</strong></summary>

**Q: Which database should I use?**  
A: PostgreSQL is recommended for production. SQLite works for development, but MySQL is also supported via Prisma.

**Q: Can I customize the UI components?**  
A: Yes! All components are built with shadcn/ui and Tailwind CSS, making them highly customizable.

**Q: How do I add custom fields to products?**  
A: Extend the Prisma schema in `prisma/schema.prisma` and run `npx prisma db push` to update your database.

**Q: Is this SEO-friendly?**  
A: Yes! Built with Next.js App Router, automatic sitemap generation, meta tags, and schema markup for optimal SEO.

</details>

**Q: Can I sell websites built with this?**

</details>
